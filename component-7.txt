## ⚠️ Catatan Penting

### Jangan Letakkan di public/
- ❌ File `.env` atau secrets
- ❌ Source code TypeScript/React (gunakan `src/`)
- ❌ File konfigurasi server
- ❌ Database files
- ❌ Backup files

### Cache Control
- File di `public/` di-cache dengan `maxAge: 1h`
- Untuk file yang sering berubah, tambahkan query string: `/iklan.js?v=2`
- Untuk ads.txt/app-ads.txt, **jangan** cache lama (verifikasi butuh fresh)

### Security
- Semua file di `public/` dapat diakses publik
- Jangan letakkan informasi sensitif
- Validasi input pada API endpoints
- Gunakan HTTPS untuk semua request
