# ALHIKMAH — Build & Release Guide

Panduan lengkap untuk build dan distribusi semua platform ALHIKMAH.

## 📦 Output Build

| Platform | Format | Path Output | Ukuran |
|----------|--------|-------------|--------|
| Web | Static | `dist/` | ~500 KB |
| Android | APK | `android/app/build/outputs/apk/release/app-release.apk` | ~8 MB |
| Android | AAB | `android/app/build/outputs/bundle/release/app-release.aab` | ~6 MB |
| iOS | Archive | `ios/build/ALHIKMAH.xcarchive` | ~15 MB |
