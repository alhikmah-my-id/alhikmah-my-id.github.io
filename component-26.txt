
## 🎨 Standar Kode

### TypeScript / React
- Gunakan **functional components** dengan hooks
- Type semua props dengan interface/type
- Gunakan `cn()` dari `@/lib/utils` untuk conditional classes
- Hindari `any` — gunakan `unknown` jika perlu

### Python
- Ikuti **PEP 8**
- Gunakan **type hints**
- Docstring untuk semua fungsi publik
- Maksimal 100 karakter per baris

### CSS / Tailwind
- Gunakan utility classes Tailwind
- Hindari arbitrary values (`w-[100px]`)
- Gunakan design tokens dari theme
