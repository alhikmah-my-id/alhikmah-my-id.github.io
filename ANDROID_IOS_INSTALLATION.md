# ALHIKMAH — Panduan Instalasi Android & iOS (Java / Kotlin / Swift)

Panduan lengkap membangun aplikasi mobile ALHIKMAH untuk platform **Android (Java & Kotlin)** dan **iOS (Swift)**, termasuk konfigurasi monetisasi Tappx, ads.txt, dan app-ads.txt.

---

## 1. Prasyarat Umum

| Tool | Versi Minimum | Keterangan |
|------|---------------|------------|
| JDK | 17 (LTS) | Wajib untuk Android Gradle Plugin 8+ |
| Android Studio | Hedgehog 2023.1.1+ | IDE resmi Android |
| Gradle | 8.7+ | Build system |
| Kotlin | 1.9.24+ | Bahasa utama Android modern |
| Xcode | 15.4+ | Wajib untuk iOS (hanya macOS) |
| CocoaPods | 1.15+ | Dependency manager iOS |
| Node.js | 18+ | Untuk tooling tambahan |
| Git | 2.40+ | Version control |
