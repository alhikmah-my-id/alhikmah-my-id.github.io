# Changelog

Semua perubahan penting pada proyek ALHIKMAH akan didokumentasikan di file ini.

Format berdasarkan [Keep a Changelog](https://keepachangelog.com/id/1.1.0/),
dan proyek ini mengikuti [Semantic Versioning](https://semver.org/lang/id/).

## [1.0.0] - 2025-12-12

### Added
- Rilis awal platform ALHIKMAH
- 22 kategori konten lengkap
- Sistem artikel SEO-ready (minimal 3000 kata)
- Table of Contents (TOC) interaktif
- FAQ Section dengan JSON-LD schema
- Media Share (WhatsApp, Facebook, Twitter/X, Telegram)
- Navigasi Next/Prev Article
- Sidebar Widgets (News Update, Popular Post, Archive)
- Tools Islami: Arabic Pegon, Kalender Hijriyah, Timer, Calligraphy
- Murotal 30 Juz audio player
- Al-Qur'an Digital 114 surah
- Integrasi Tappx Ads dengan rotasi 6 App Key
- File ads.txt & app-ads.txt lengkap
- PWA manifest.json
- Backend Express.js dengan REST API
- Python automation: artikel.py, generator.py, tools.py
- Android app (Kotlin & Java)
- iOS app (Swift)
- SEO optimization (Open Graph, Twitter Card, JSON-LD)
- Sitemap.xml & robots.txt otomatis
- Deployment guide (VPS, Vercel, Docker)

### Security
- HTTPS-only configuration
- Network security config untuk Android
- App Transport Security untuk iOS
- CORS dengan credentials support
